`fallback.fnt` and `fallback-table-8-14.png` are rasterized from DejaVu Sans
Mono by `tools/scripts/make_fallback_font.py`. DejaVu fonts are distributed
under the Bitstream Vera / DejaVu license (free to use, copy and redistribute);
see https://dejavu-fonts.github.io/License.html.

They are only used when no Playdate SDK is available. With `PLAYDATE_SDK_PATH`
set, the simulator uses the SDK's system font instead.
